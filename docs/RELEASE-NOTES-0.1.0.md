# fast-iso8601-rs 0.1.0

Initial Rust-backed drop-in replacement for `iso8601==2.1.0`, preserving the
`iso8601` namespace and providing a Python 3.7-compatible universal fallback.

This note is a release input, not evidence that publication occurred. Final
artifact filenames, checksums, benchmark evidence and validation counts must be
attached by the guarded release workflow.
