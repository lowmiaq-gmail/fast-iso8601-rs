# SEO Report

## Search intent

Primary intent: Python users seeking a faster `iso8601` parser without changing
imports or datetime behavior. Secondary intent: Rust-backed ISO 8601 parsing,
Python 3.7 fallback and PyO3 datetime parser packaging.

## Metadata coverage

- project summary includes `Rust-backed`, `drop-in replacement`, and pinned
  upstream version;
- keywords cover `iso8601`, `datetime`, `parser`, `pyo3`, `rust`, and
  `drop-in-replacement`;
- README title, first paragraph and example state the import namespace and use;
- project URLs include homepage, repository, issues and changelog.

## Claim policy

Do not publish a numeric speed claim until an exact release wheel has raw-sample,
median and p95 evidence. Do not claim compatibility with versions after 2.1.0 or
platforms whose packaged-wheel CI has not passed.
